# Revisión de mantenimiento

Se tomó como fuente el ZIP motor-senales-nlp_repo_2.zip y se preservaron los 13
archivos congelados. El PDF acompañante fue leído como referencia y no sustituye
el Word institucional. ChatGPT/Codex asistió en esta revisión del código y la
documentación; la declaración de IA del Word histórico no se modificó.

La ejecución T4 es evidencia aportada por el autor. No se ha repetido durante esta
revisión. El entorno de CI comprueba software e integridad, no rendimiento de GPU.

## Aspectos que requieren decisión del autor

- Las licencias declaradas de los checkpoints necesitan verificación individual;
  la licencia del código de este repositorio no resuelve esa cuestión.
- El generador histórico agrupa algunas categorías no reconocidas como deuda de
  corto plazo. Se conserva esa lógica para reproducir el material; no debe usarse
  como control de idoneidad financiera.
- El corpus sintético no constituye validación externa ni demuestra rendimientos
  futuros. Los modelos reciben texto, no una cartera completa.
- Se preserva la conclusión: la hipótesis de ventaja de un modelo en español se
  refutó; tres de cinco umbrales no se cumplen y no se autorizan señales automáticas.

Las mejoras son de mantenimiento. No modifican cifras, gráficos ni conclusiones
históricas. El historial de Git conserva la versión anterior del repositorio.
